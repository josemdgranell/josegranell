# Portfolio de José Granell — GitHub Pages

Esta carpeta contiene la última versión de la web, lista para GitHub Pages. No necesita instalación ni compilación.

## Publicación

1. Crea un repositorio público en GitHub (por ejemplo, portfolio).
2. Sube el contenido de esta carpeta a la raíz del repositorio. index.html debe quedar en la raíz, junto a assets y projects. No subas el ZIP ni una carpeta contenedora.
3. Conserva el archivo .nojekyll, que desactiva el procesamiento de Jekyll. Si tu explorador no lo muestra, activa la visualización de archivos ocultos.
4. En Settings → Pages → Build and deployment, selecciona Deploy from a branch.
5. Selecciona main y /(root), y pulsa Save.
6. Espera a que GitHub termine la publicación. La dirección aparecerá en Settings → Pages.

Las rutas son relativas: funcionan tanto en https://usuario.github.io/portfolio/ como en https://usuario.github.io/. Cada proyecto usa su página .html; se puede abrir directamente y recargar.

Para actualizar, sustituye los archivos modificados en main. GitHub Pages vuelve a publicar automáticamente.

## Contenido

La web mantiene el grid, Offgrid en tercera posición, las barras del hero separadas y el reproductor compacto. No incluye selector de vistas ni modo oscuro.

La música se carga desde su URL externa de Framer. El formulario de contacto abre el programa de correo del visitante mediante mailto; no utiliza un servidor de envío.

Documentación: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
